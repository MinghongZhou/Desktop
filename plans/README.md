# Claude Plans Tracker

This directory tracks plans, tasks, and progress for Claude-assisted work.

## Structure

- `active/` — Plans currently in progress
- `completed/` — Plans that have been finished
- `archived/` — Old or cancelled plans

## Plan Format

Each plan is a Markdown file named `YYYY-MM-DD-<short-title>.md` and follows this template:

```
# Plan: <Title>

**Date:** YYYY-MM-DD
**Status:** active | completed | archived

## Goal
What we are trying to achieve.

## Steps
- [ ] Step 1
- [ ] Step 2

## Notes
Any relevant context or decisions.
```
